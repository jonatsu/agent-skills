# Cognitive and Learning Disabilities

WCAG covers only part of what people with cognitive and learning disabilities need. W3C's Working Group Note
"Making Content Usable for People with Cognitive and Learning Disabilities" (COGA, 29 April 2021,
<https://www.w3.org/TR/coga-usable/>) gives the rest as user needs and design patterns. It is informative
guidance beyond WCAG 2 and is not required for conformance, so never fail a criterion on its basis.

## The Eight Objectives

Organize a design or a review for these users by the note's objectives:

1. Help users understand what things are and how to use them.
2. Help users find what they need.
3. Use clear and understandable content.
4. Help users avoid mistakes and know how to correct them.
5. Help users focus.
6. Ensure processes do not rely on memory.
7. Provide help and support.
8. Support adaptation and personalization.

Each objective lists its design patterns in the note. Cite the pattern by name with a recommendation.

## The Criteria That Require It

At Level A and AA, these criteria carry the binding part: 1.3.5, 2.2.1, 2.2.2, 2.4.6, 3.2.3, 3.2.4, 3.2.6,
3.3.1, 3.3.2, 3.3.3, 3.3.4, 3.3.7, and 3.3.8. Report a failure only against one of them. The AAA criteria 1.3.6,
2.2.6, 3.1.3, 3.1.4, 3.1.5, and 3.3.9 apply only when the user names Level AAA.

For plain language, load the `writing-for-humans` skill. Judge text by whether its readers can find, understand,
and use it, not by a readability score. 3.1.5 Reading Level is AAA, so below an AAA target a score decides
nothing.
