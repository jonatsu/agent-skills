- License: `AGPL-3.0-or-later`

The repository's `package.json` declares the licence, and each file's frontmatter claims Apache-2.0. The two files
supplied the ideas of establishing requirements before judging proportion, reviewing data ownership and
consistency, asking whether failures are visible and recovery tested, checking that decisions are recorded,
checking that a boundary is enforced rather than conventional, keeping framework types out of the core, and
applying a style only where it pays. Every rule was written independently, and no text or code was copied.
