# Contributing

Contributions are welcome.

## Before you start

- Check existing issues and pull requests.
- Open an issue first for large or unclear changes.
- Keep changes focused and easy to review.

## Development

1. Fork or clone the repository.
2. Create a branch with a short, descriptive name.
3. Make the smallest useful change.
4. Run the project checks documented in the README.
5. Open a pull request using the template.

## Pull request expectations

- Explain the problem and the solution.
- Link related issues.
- Include tests or manual verification when relevant.
- Update documentation for user-facing changes.

## Communication

Be respectful, specific, and constructive. If this repository has a code of
conduct, it applies to all project spaces.
