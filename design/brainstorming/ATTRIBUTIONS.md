## Superpowers Base Interaction Model

- Original author: Jesse Vincent
- Upstream project: [obra/superpowers](https://github.com/obra/superpowers)
- Source path: [`skills/brainstorming/SKILL.md`](https://github.com/obra/superpowers/blob/b36e0829c6d0140e93cfef2ca599b1b07d4a7797/skills/brainstorming/SKILL.md)
- Source revision: `b36e0829c6d0140e93cfef2ca599b1b07d4a7797`, inspected 2026-08-12
- Relationship: adapted interaction model, independently expressed

The source provides the base conversational model: inspect context, ask one consequential question at a time, present a
small set of approaches with tradeoffs and a recommendation, and scale the discussion to the idea. This version stops
at an explicitly incomplete handoff draft. It excludes the upstream implementation router, mandatory approval for every
creative task, section-by-section approval, complete-specification workflow, visual-companion server, and
`writing-plans` coupling. No upstream prose, code, examples, scripts, or assets are copied, translated, or vendored.
