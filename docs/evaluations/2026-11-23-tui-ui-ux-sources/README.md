# Full-Screen Terminal Interfaces: Sources for `tui-ui-ux`

Date: 2026-11-23. Prepared for `tui-ui-ux`, the sibling of `ui-ux-skills/cli-ui-ux` for full-screen terminal
interfaces: layout, keybindings, focus, resizing, redraw, screen-reader behaviour, and review.

| File                                           | What it holds                                                                                                                     |
| ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| [third-party-skills.md](third-party-skills.md) | Published TUI design skills with licences, pins, scope, defects, and the ideas worth taking                                       |
| [primary-sources.md](primary-sources.md)       | Terminal mechanics, framework guidance, keybinding conventions, accessibility, testing, and design guides, each fact with its pin |

Two Sonnet research lanes wrote these files. Each marks what a source says apart from its own inference and lists what
it could not read. The accessibility evidence for full-screen interfaces is thin: one practitioner's account, vendor
documentation, and the WCAG2ICT note, with no independent study found.
