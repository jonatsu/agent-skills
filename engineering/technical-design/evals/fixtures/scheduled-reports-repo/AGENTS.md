# Repository Instructions

This repository holds the specifications and designs for the reporting product's scheduled report delivery. The
implementation lives in a separate repository.

- Accepted requirements specifications live in `docs/specs/`.
- Designs live in `docs/plans/`, named `<name>-design.md`. A design names the specification revision it realizes.
- Write in plain English, wrap Markdown at 120 columns, and link to a document instead of repeating its content.
