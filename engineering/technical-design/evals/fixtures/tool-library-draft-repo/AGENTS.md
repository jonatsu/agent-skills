# Repository Instructions

This repository holds the planning documents for the neighborhood tool library. Plans, drafts, and designs live in
`docs/plans/`, named `<name>-overview.md`, `<name>-draft.md`, or `<name>-design.md`.

The governing overview is `docs/plans/tool-library-overview.md`. Write in plain English and keep each document under
200 lines. Link to another document instead of repeating its content.
