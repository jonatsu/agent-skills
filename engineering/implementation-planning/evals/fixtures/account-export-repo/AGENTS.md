# Repository Instructions

`accounts` is the account service: profile data, account activity, and administrative tools.

- `just test` runs pytest; `just lint` runs ruff.
- Specifications live in `docs/specs/`, designs in `docs/design/`, and implementation plans in `docs/plans/`. A plan
  names the specification and design revisions it implements.
- Requirement anchors (for example `#req-format`) are stable. Link to them rather than restating the requirement.
- Changes are reviewed on a pull request by another maintainer. Record review findings and their resolution there.
