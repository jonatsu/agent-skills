### Anthropic: Prompting best practices

- Source: <https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/claude-prompting-best-practices>
- License: `LicenseRef-Proprietary`
- Version: read 2026-09-28

The page states no license, so Anthropic retains all rights; nothing was copied. It supplied the receiver framed as a
capable colleague who lacks the writer's context, giving the reason behind a constraint so the model generalizes,
separating instructions, context, examples, and input, and stating the target behavior rather than a prohibition. It
also supplied calm emphasis, because forceful wording makes current models over-apply a rule.

- License: `MIT`
- Version: `d3b8a3e908904e242ed2dbe66af62cca71131419`

The skill supplied the advice-only stance for improving a user's prompt, a check for missing context such as
acceptance criteria and scope boundaries, and asking at most three questions before rewriting. It also supplied
delivering a diagnosis with the rewritten prompt in one fenced block and the reason for each change. Nothing was
copied.
